### 🚀 What I Can Do

**📱 Cross-platform mobile (Flutter / Dart)**
- Production apps for Android and iOS from a single codebase
- Clean, layered architecture with separate `domain`, `data` and `di` packages
- State management with BLoC/Cubit, dependency injection with get_it
- Reusable generic network layers, pagination and loading/error states
- Localized, RTL-ready apps (Arabic & English)
- Pixel-accurate UI implemented from Figma designs
- Flutter desktop and web dashboards for admin and internal operations

**🍎 Native iOS (Swift)**
- SwiftUI and UIKit apps, plus legacy Objective-C
- MVVM, networking and form handling

**🤖 Native Android (Kotlin)**
- Jetpack Compose and XML-based apps
- MVVM with modern Android architecture components

**🖥️ Backend (C# / .NET)**
- REST APIs with ASP.NET Core Web API
- Clean Architecture, Entity Framework Core, SQL Server
- Authentication, payment integration and admin back-offices for mobile apps

**🌐 Web**
- React and Angular front ends with TypeScript
- Company profile websites and landing pages (HTML, CSS, JavaScript)

**🛠️ Everything around the code**
- Taking an idea from Figma design → mobile app → API → admin dashboard
- Publishing to Google Play and the App Store
- Git-based workflows and code review
